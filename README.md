# Internship Tasks – Data Analytics

## Overview
This repository contains internship tasks completed as part of the Data Analytics internship program.

---

## Task 1: Web Scraping
In Task 1, web scraping was performed using Python. The program sends a request to a website, parses the HTML content, and extracts useful data using BeautifulSoup. This task demonstrates the ability to collect data from online sources.

### Skills Gained
- Understanding website structure
- Data extraction using Python
- Working with BeautifulSoup

---

## Task 3: Data Visualization
In Task 3, data visualization techniques were applied using Python. Sample sales data was visualized using bar charts and line charts to understand trends and patterns.

### Skills Gained
- Data visualization
- Graph interpretation
- Using Matplotlib for charts

## Conclusion
These tasks demonstrate practical knowledge of data collection and data visualization. The completed tasks showcase analytical thinking and Python programming skills required for data analytics roles.
